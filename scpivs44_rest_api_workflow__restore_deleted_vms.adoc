= SnapCenter Plug-in for VMware vSphere를 사용하여 삭제된 VM을 복원하는 REST API 워크플로
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
VMware vSphere REST API용 SnapCenter 플러그인을 사용하여 VM 백업에 대한 복구 작업을 수행하려면 규정된 REST API 호출 순서를 따라야 합니다.

각 REST API에 를 추가합니다 `\https://<server>:<port>` REST API의 전면에서 전체 끝점을 형성합니다.

|===
| 단계 | REST API | 설명 


| 1 | 로 이동합니다 `\http://<vCenter-IP>/mob` | VMware Managed Objects URL에서 데이터스토어 *moref*를 찾습니다. 삭제된 VM이 있던 데이터스토어의 moref를 기록해 둡니다. 


| 2 | `/4.1/datastores/{moref}/backups` | `Get Datastore Backups`지정된 데이터 저장소에 대한 백업 목록을 검색합니다. 1단계에서 얻은 *moref*를 전달합니다. 복원하려는 백업의 *backupId*를 기록해 두십시오. 


| 3 | `/4.1/backups/{backupId}` | `Get Backup Details` 지정된 백업의 세부 정보를 검색합니다. 2단계에서 얻은 *backupId*를 전달합니다. 엔티티 목록에서 삭제된 VM과 일치하는 *entityName*을 찾고 *UUID*를 기록합니다. 


| 4 | `/4.1/vm/backups/{backupId}/snapshotlocations` | `Get snapshot locations`지정된 백업에 대한 스냅샷 위치를 검색합니다. 2단계에서 얻은 *backupId*를 전달합니다. *snapshotLocationsList* 정보를 기록해 두십시오. 


| 5 | `/4.1/datastores/{moref}/availableEsxHosts` | `Get available ESX Hosts`백업이 저장된 호스트에 대한 정보를 검색합니다. 1단계에서 얻은 *moref*를 전달합니다. *availableEsxHostsList* 정보를 기록해 둡니다. 


| 6 | `/4.1/vm/{uuid}/backups/{backupId}/restoreVm` | `Restore a VM from a backup` 지정된 백업을 복원합니다. 3단계에서 얻은 *UUID*를 전달합니다. 2단계에서 얻은 *backupId*를 전달합니다. *restoreLocations* 속성에는 4단계의 *snapshotLocationsList* 정보를 전달하고, *esxHost* 속성에는 5단계의 *availableEsxHostsList* 정보를 전달합니다. VM 백업이 부분 백업인 경우  `restartVM` 매개변수를 *false*로 설정합니다. *참고:* 템플릿 VM은 복원할 수 없습니다. 
|===
