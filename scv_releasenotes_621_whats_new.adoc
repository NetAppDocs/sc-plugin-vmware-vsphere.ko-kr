= SnapCenter Plug-in for VMware vSphere 6.2.1의 새로운 기능
:allow-uri-read: 


[role="lead"]
SnapCenter Plug-in for VMware vSphere 6.2.1은 유지 관리 릴리스입니다. 이 릴리스는 어플라이언스와 함께 제공되는 타사 소프트웨어를 업데이트하고 SnapCenter Plug-in for VMware vSphere 6.2 릴리스 이후 발견된 문제에 대한 수정 사항을 포함합니다.



[[updated-components]]
== 업데이트된 구성 요소

|===
| 구성 요소 | SnapCenter Plug-in for VMware vSphere 6.2.1 


| Java 런타임 | OpenJDK 21.0.12 


| .NET 런타임 | .NET 10.0.11 


| 어플라이언스 운영 체제 | Debian 13 
|===


[[fixed-issues]]
== 해결된 문제

업그레이드하기 전에 해당 릴리스에서 수정된 알려진 문제를 검토하는 것이 좋습니다.

* VMDP-7072: Oracle Cloud의 클라우드 관리형 ONTAP을 스토리지 시스템으로 추가할 수 있습니다.
* VMDP-7052: VM을 다른 위치로 복원할 때 VM 스토리지 정책이 유지되므로 기본값이 아닌 정책을 사용하는 VM의 경우 더 이상 복원이 거부되지 않습니다.
* VMDP-7027: 지원 로그 번들에는 구성된 스토리지 시스템 목록이 포함됩니다.
* VMDP-6987: vCenter가 데이터 저장소를 일시적으로 사용할 수 없다고 보고하는 경우에도 가상 디스크 연결 또는 복원 작업이 더 이상 실패하지 않습니다.
* VMDP-6965: 일정 기록 하나가 불완전할 때 일정 페이지가 더 이상 로드에 실패하지 않습니다.
* VMDP-6952: 사용자가 리소스 그룹을 삭제할 권한이 없는 경우 권한 메시지가 표시됩니다.
* VMDP-6939: 유지 관리 콘솔에서 더 이상 VMware 툴이 누락되었다는 메시지가 표시되지 않습니다.
* VMDP-6935: 개별 파일을 복원하기 위해 백업을 탐색하는 작업이 더 이상 실패하지 않습니다.
* VMDP-6933: 새 어플라이언스 배포 시 최초 설정 과정에서 더 이상 오류가 발생하지 않습니다.
* VMDP-6931: 보조 백업 정리 시 더 이상 접근할 수 없는 특정 볼륨에서 몇 시간씩 기다리지 않습니다. 다른 볼륨은 계속 처리됩니다.
* VMDP-6817: 소스 ONTAP 볼륨의 이름을 변경해도 보조 백업이 이전 이름으로 고정되거나 더 이상 유효하지 않은 항목이 표시되는 문제가 해결되었습니다.
